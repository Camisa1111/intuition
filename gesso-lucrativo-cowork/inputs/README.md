# Inputs — materiais para análise

Coloque aqui os arquivos que o agente deve ler **antes** de rodar o pipeline.

## Sugestão de nomes

| Arquivo | Conteúdo |
|---------|----------|
| `landing-page.md` | Texto completo da LP |
| `criativos-transcricoes.md` | GL-01 a GL-06 com timestamps |
| `depoimentos.md` | Nome, cidade, resultado R$ (quando tiver) |
| `comentarios-anuncios.md` | Copy-paste de comentários Meta |
| `metricas.csv` | ID criativo, CTR, gasto (opcional) |

## Formato
Markdown ou `.txt` em português. Quanto mais verbatim, melhor o VOC.
